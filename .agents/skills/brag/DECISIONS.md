# Decisions

| Date | Decision | Why | Supersedes |
|---|---|---|---|
| 2026-11-03 | Product-native motion runs on GSAP 3.13 (vendored `runtime/gsap.js`) driven by a paused master timeline in `timeline.js`, with `runtime/motion.js` (`BRAG.fx`) as the effects menu | Videos came out static: the skill had no text-effect or transition vocabulary and only 6 easing curves. GSAP keeps frame-exact seeking; tested identical frames in forward and reverse seek order | |
| 2026-11-03 | New `--energy` option (calm / lively / punchy / hype, default from the tone) with rules in `references/motion.md`; at lively+ the motion is written before the storyboard review and panels get motion strips (`panels.mjs --strip`) | Motion was treated as polish added after approving stills, so it stayed minimal | |
| 2026-11-03 | Don't adopt HyperFrames as the renderer; borrow ideas only | Same render architecture as brag; would replace working code with a heavier stack | |
| 2026-11-03 | Ten motion styles (HTML + GSAP) in `motion-styles/`, adapted from lemo-opuscar (MIT): dark-keynote, glass-product, living-screencast, swiss-motion, blueprint, whiteboard (most useful for product videos) + caption-news, telestrator, halftone-dossier, game-show (best for viral/social shorts) | Fil asked for the 5 most useful plus the 5 best for viral videos; HTML + GSAP so they can hold real product UI and use the motion menu | |
| 2026-11-03 | Style is picked from a reel of every style moving, before the storyboard | Picking from names or stills hid what the styles do | |
| 2026-11-03 | The style picker is prebuilt once (`assets/style-previews/`, published as an Artifact) and only opened at intake; rebuilt only when a style changes | Rebuilding it on every /brag call would waste tokens (Fil) | 2026-11-03: Style is picked from a reel |
| 2026-11-08 | Product UI in a video moves only with the app's own animations: `tools/ui-motion.mjs` inventories them into `ui-motion.js`, `fx.ui`/`fx.uiAnim` replay them on the timeline (instant where the app is instant); brag's motion menu is for the film layer around the UI only; timeline.js turns CSS transitions off | Fil: brag layered its own springs, staggers and text effects on real UI, which made the product look worse than it is | 2026-11-03: Product-native motion runs on GSAP (scope narrowed to the film layer) |
| 2026-11-08 | Four more motion styles from a survey of prompt-motion.com: kinetic-reel, chart-room (real numbers only), manim-explainer, morph-ui; ideas only, no prompt text or media copied (the gallery states no licence) | Fil asked what the gallery offers brag; these looks were missing (kinetic type, data, diagram explainers, shape morphs) | |
| 2026-11-03 | `fx.scenes` sets scene visibility per frame from each scene's window, not with GSAP sets | Zero-duration GSAP sets didn't revert reliably on backward seeks: later scenes showed at t=0 | |
