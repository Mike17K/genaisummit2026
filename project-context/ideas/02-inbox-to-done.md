# 2. Inbox to done

**Direction:** Agents at the office. **Risk:** Low. **Status:** crowded, needs polish.

- **Job:** read a real inbox, draft replies, book the meeting, file the invoice, then show a diff of the day to approve.
- **Wow moment:** one click approves 12 actions at once.
- **Why it scores:** listed in the deck so judges know it; a polished approval diff signals craft.
- **Risks:** other teams will likely pick it; differentiate via a specific persona.

## Judge angle
- **Track:** Voice & Enterprise
- **Twist to make it memorable:** A 'day diff' like a pull request: judges approve or reject each action. Add an 'agent said no' moment where it declines to send something risky.
- **Production proof to show:** Permission scopes, undo, trace of every tool call, cost per day.
