# 12. Fifty papers before lunch

**Direction:** Agents in the lab. **Risk:** Medium.

- **Job:** read the literature on a topic, propose the next experiment, and cite the page behind each claim.
- **Wow moment:** click any claim and jump to the exact quoted passage.
- **Why it scores:** sources shown, which the field rules reward; a real researcher user.
- **Risks:** hallucinated citations; verify every quote against the source text before showing it.

## Judge angle
- **Track:** Biotech & AI (LifeTech Park)
- **Twist to make it memorable:** Ask the agent to find where two papers disagree and propose the experiment that settles it, with the quoted page for each side.
- **Production proof to show:** Verified quotes only (reject any citation not found in source), reproducible run, sources list.
