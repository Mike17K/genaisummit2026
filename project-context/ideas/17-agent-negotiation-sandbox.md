# 17. Agent-to-agent negotiation

**Direction:** Agents first (agents are the user or operator). **Risk:** High. **Track:** Voice & Enterprise.

- **Who the user is:** A person who hates haggling (rent, supplier prices, freelance rates), and the counterparty's agent.
- **Job:** Your agent negotiates against the other side's agent within limits you set (walk-away price, must-haves) and returns a signed summary.
- **Wow moment:** Two agents negotiate live on screen with different goals; you only see the final deal and the concessions that mattered.
- **Sponsor stack:** Wonderful voice track if selected; text negotiation as the safe fallback.
- **Risks:** Needs a believable counterparty; script the other agent and make it hard.

## Judge angle
- **Twist:** Show the walk-away limit holding when the other agent applies pressure, then a human-readable concession log.
- **Production proof to show:** Hard limits enforced in code not prompt, full transcript, human sign-off on final terms.
