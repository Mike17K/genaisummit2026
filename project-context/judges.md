# Judges and judging lens

## What is confirmed
- **No named judge list is published** (site, Luma, kickoff deck). Luma only has a "Judge" ticket type. Ask organisers at kickoff.
- **Quintessential** (Athens product studio) supplies sponsor, mentors and judges (kickoff deck). People named: founders Alex Daskalakis, Socrates Charisis, Kostas Kopanidis. Kostas presents the deck and is on the floor all weekend.
- **Criteria (deck + site):** Usefulness, Craft, Aura points. "Would a real person use this on Tuesday?" / "It runs live. It survives the ugly case." / "Taste, nerve, a surprise."
- **Lens:** "would it survive real users?" Quintessential claims 150 projects delivered, 90+ clients, 99.99% uptime.
- **Semifinal:** 8 teams pitch 3 min each to the judges, Sun ~19:00. Finals: 4 teams, Mon on the Summit stage (SNFCC).

## What Kostas says about himself (deck slide 9)
Codes with agents, infrastructure, DevOps. Building Ostria (their AI arm / agentic platform) and Conduit. Experiments making games with AI. "I deploy on Fridays and spend more tokens than I care to admit."

## Inferences (not confirmed)
- Judges likely include sponsor and partner people (Wonderful, fal, Oumi, Google, treg) alongside Quintessential.
- They are engineers who build agents for a living, so they notice: fake demos, missing error handling, no tracing, hand-waved auth, burning tokens pointlessly.
- They reward: visible tool calls and steps, a nasty edge case handled live, real data, a cost/latency story, and a clear person with a job.

## Cheat sheet for every idea
1. Name the one person and the one job in one sentence.
2. Show real data, not lorem ipsum.
3. Stream the agent's steps, tool calls and sources on screen.
4. Demo one ugly case live (bad input, API failure) and show recovery.
5. Show the production thinking: permissions, approval step, logs/trace, cost per run.
6. Have a cached run or video as plan B.
7. Finish with "what we'd build in one more week".
